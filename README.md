# Data Professionals Survey Analysis using Power BI

## Project Overview
This project analyzes survey data collected from data professionals across different countries and industries using Power BI.

## Objectives
- Analyze salary distribution across different job roles.
- Identify the most popular programming languages.
- Understand job satisfaction and work-life balance.
- Explore career trends across different industries.
- Analyze demographic information of data professionals.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights
- Salary comparison across different job roles.
- Most preferred programming languages.
- Work-life balance and salary satisfaction.
- Job difficulty and career preferences.
